# Проект: Дневник смен водителя

Структура: server/ (FastAPI, Python 3.12, pytest) и app/ (Flutter 3, Dart 3).

## Предметная область (не нарушать)
- Деньги только int (тенге). Никаких float/double.
- Время хранится и передаётся как ISO 8601 СО смещением (например +05:00). Время без смещения сервер отклоняет (422).
- «День поездки» = локальная дата начала поездки в её собственном смещении, НЕ UTC и НЕ часовой пояс сервера/устройства.
- Поездка: id (строка, задаёт клиент), start, end, amount, payment ("cash" | "card"), commission.
- Валидация: amount > 0; end строго позже start; payment только cash/card; 0 <= commission <= amount.
- Идемпотентность: POST с существующим id и идентичными данными → 200 и существующая запись, дубля нет. Тот же id с другими данными → 409. Проверка и вставка выполняются под одной блокировкой (нет гонки).
- Сводка дня: trips_count, revenue (сумма amount), commission (сумма commission), net = revenue − commission, cash_total и card_total (суммы amount по способу оплаты).
- ЭТАЛОН (обязателен как тест): поездки t1 и t2 из примера задания за 2026-10-01 дают: trips_count=2, revenue=3900, commission=585, net=3315, cash_total=1500, card_total=2400.

## Архитектура (расширяемость)
- Сервер: api/ (тонкие роуты) → services/ (чистая бизнес-логика) → repositories/ (интерфейс + реализация JSON). Роуты без логики. Новое хранилище = новая реализация интерфейса.
- Flutter, feature-first: lib/core (тема, сеть, форматирование, конфиг), lib/features/trips/{data,domain,presentation}. UI → контроллер → абстрактный репозиторий → API-клиент. Виджеты не ходят в сеть. Новая функция = новая папка в features/.
- Единый формат ошибок API: {"error": {"code": "...", "message": "..."}}.

## Ловушки (проверяй себя)
- Dart: DateTime.parse с суффиксом смещения возвращает UTC и теряет смещение. Время поездки показывай в смещении САМОЙ поездки (смещение разбирай из строки), а не в зоне устройства.
- Dart: toIso8601String() у локального DateTime выдаёт строку БЕЗ смещения. При отправке формируй строку со смещением явно.
- Android-эмулятор ходит на сервер по 10.0.2.2, web и desktop по localhost. Адрес берётся из конфига (--dart-define=API_URL).
- Шрифты кладём в assets/fonts и объявляем в pubspec (без загрузки из сети, чтобы работали сборка и тесты).
- Только Material 3 и актуальные API Flutter (withValues вместо withOpacity).

## Дизайн: «чек» (главный экран)
- Фон страницы: холодный светло-серо-голубой (#EEF1F6). Бумага чека: тёплый кремовый (#FFF8E1), слегка повёрнута (около −1°), мягкая тень, нижний край рваный (зубчики через CustomClipper). Текст тёмно-серый/синеватый (#1E293B), вторичный серый (#6B7280). Все цвета только в теме.
- Шрифты: моноширинный (JetBrains Mono) для строк чека; жирный геометрический (Manrope ExtraBold) для итога «На руки».
- Структура чека сверху вниз: заголовок «Дневник смен» по центру жирным, дата дд.мм.гггг серым; строки поездок «08:10–08:32 карта» слева и «2 400 ₸» справа (нал. = «нал.», карта = «карта»); пунктирная линия; строки «Поездок», «Выручка», «Комиссия» (со знаком минус: −585 ₸), «Наличные / карта» (1 500 / 2 400); пунктирная линия; «На руки» мелко слева и крупная цифра (≈40sp) справа.
- Формат денег: разделитель тысяч неразрывный пробел, затем неразрывный пробел и «₸»; минус настоящий (U+2212).
- Сетка отступов 8. Поддержка тёмной темы (чек остаётся светлым).
